PWA Icons Required
==================

Place the following icon files in this directory:

  icon-192x192.png  — 192×192 px  (required for Android home screen)
  icon-512x512.png  — 512×512 px  (required for splash screen / install prompt)

Recommended: use a maskable icon so it renders correctly on all Android shapes.
You can generate icons from an SVG at https://maskable.app or https://realfavicongenerator.net
